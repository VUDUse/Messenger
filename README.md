Десктопное приложение-мессенджер на **C# / WPF** с хранением данных в **MSSQL** через **Entity Framework**.

## Описание

Messenger — это клиентское приложение для обмена сообщениями, реализованное в архитектуре WPF-приложения с доступом к базе данных через Entity Framework и LINQ-запросы. Проект решает базовую задачу мессенджера: регистрация/вход пользователей, хранение переписки и отображение сообщений в удобном десктопном интерфейсе.

## Технологический стек

- **C#** — основной язык разработки
- **WPF (Windows Presentation Foundation)** — построение пользовательского интерфейса
- **MSSQL (Microsoft SQL Server)** — база данных
- **Entity Framework** — ORM для работы с БД
- **LINQ** — запросы к данным
